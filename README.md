# MSH Portfolio

A collection of practical electrical and electronic engineering projects
covering embedded systems, sensors, control systems, circuit design,
simulation, prototyping and testing.

## Projects

### 01 — Control & Server Room Monitoring System

An Arduino-based monitoring and control system combining temperature
monitoring, movement detection, automated lighting and door activity
indication.

[View project](01-server-room-monitoring/README.md)

### 02 — Sustainable Smart Lighting System

An Arduino-based smart lighting system using ultrasonic occupancy detection,
ambient-light sensing and user control to reduce unnecessary lighting.

[View project](02-sustainable-smart-lighting/README.md)

## Development Approach

Projects are developed through a practical engineering workflow:

1. Define the requirements
2. Select components
3. Design the circuit
4. Develop the embedded software
5. Simulate the design
6. Test the system
7. Build the physical prototype
8. Measure and evaluate performance
9. Identify limitations
10. Improve the design

## Tools
